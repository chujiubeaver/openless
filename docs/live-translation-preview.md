# 实时英文翻译预览（Live English Translation Preview）

录音期间在胶囊中实时显示所说内容的英文翻译。**仅供查看**：不插入文档、不进历史，录音结束即清除。

设计与实现细节见 [live-translation-preview-design.md](./live-translation-preview-design.md)。

## 开启方式

设置 → 录音与输入 → 「实时英文翻译预览」。默认关闭。

仅在以下组合下可开启（其余组合开关置灰并显示原因）：

- 识别管线为**多模态**（Multimodal）；
- Omni 渠道类型为**百炼（dashscope-omni）**。

开启后，录音时胶囊的原文草稿槽位会显示带 `EN` 小标的英文译文行；松键后译文最多再保留约 1.5 秒（尾段翻译），随后随胶囊终态一起消失。

## 计费与隐私

- 音频会**额外**实时流式发送到当前百炼渠道的翻译模型 `qwen3.8-livetranslate-flash-realtime`，复用该渠道已有的 API Key 与端点，不新增任何凭据。
- 按音频时长计费（官方输入定价 7 token/秒），与主识别链路的费用相互独立。
- 主链路（多模态识别）本就会在松键后上传整段音频；本功能新增的是**录音期间的实时上传**。
- 译文只在内存与界面事件中出现：不写入历史、不参与润色上下文、不进入云同步文档、不写日志（日志只记录字节数与错误码）。

## 行为与限制（v1）

| 场景 | 行为 |
|---|---|
| 传统管线 + 流式 ASR（已有实时原文） | 不生效（避免双行文本），开关置灰 |
| 传统管线 + 稳定模式 + 百炼 ASR | v1 暂不支持（后续版本评估） |
| QA / 划词润色 / Voice Edit / 云笔记 / 远程输入音频 | 不生效（仅普通听写 + 本机麦克风） |
| 凭据缺失 / 连接失败 / 中途断线 | 静默隐藏译文行，不影响主识别链路，不弹错误 |
| 翻译队列积压超过 15 秒 | 本次会话预览停止（保护内存），主链路不受影响 |
| 录音中关闭开关 | 本次会话按开始时的设置继续，下次录音生效 |
| Windows 分离字幕轨道 | v1 不支持（译文行仅在 macOS 胶囊窗口内渲染） |

## 故障排查

- 开关置灰：按提示切换到多模态管线并选择百炼 omni 渠道。
- 开启后无译文：查看应用日志中的 `[live-translation]` / `[qwen-livetranslate]` 警告（连接超时、鉴权失败、模型未开通等都会静默降级为不显示）。
- 确认账号已开通 `qwen3.8-livetranslate-flash-realtime` 模型（阿里云百炼控制台）。
